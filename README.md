# Retail Sales & Seasonal Trend Analysis

## Project Overview
This project analyzes retail and warehouse sales data to identify seasonal patterns, product performance, and supplier contribution using Python. The goal is to uncover trends that help businesses understand demand fluctuations and make data-driven decisions.

## Dataset
The dataset contains retail and warehouse sales records across multiple product categories and suppliers.

Key features include:
- Sales date
- Product category
- Supplier information
- Retail sales
- Warehouse sales

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
